## 📁 Repository Structure

- `THEME/`: Photography submissions organized by theme and prompt.
  - `TOPIC - REFLECTION/`: Submissions capturing reflections and light play.

---

## 📷 How to Submit Photos

1. Export your photograph in standard format (`.jpg` or `.jpeg`).
2. Follow the naming convention: `YourName01.jpg` (e.g., `Sagar01.jpg`).
3. Place your file in the corresponding topic folder under `THEME/`.
4. Open a Pull Request or push your branch.
